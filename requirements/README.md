# 需求文档

本目录记录知乎回答朗读扩展的产品需求，独立于实现和测试。当前第一版需求稿为 [v0.1](versions/v0.1.md)，状态为**草稿，待确认**；文档版本不代表软件发布版本。

## 目录与迭代方式

- `versions/`：按版本保存需求稿。每版在文首记录状态、日期和相对上一版的主要变化。
- `v0.1` 是起点。讨论中的澄清可以先更新当前草稿并在变更记录中说明；形成新的评审基线后，复制为下一个版本，保留旧版以便回看。
- 新版本应更新本页的当前版本链接，并说明哪些需求、验收口径或未决事项发生了变化。已经确认的事项写明结论；尚未确认的事项继续保留，不把推测写成要求。
- 文档中的「第一版」是目标范围，不表示功能已经实现或验证。实现现状和安装方法以项目说明及实际代码为准；发现差异时先确认产品意图，再更新对应文档或实现。
