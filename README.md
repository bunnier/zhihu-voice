# 知乎回答朗读

Chrome 和 Microsoft Edge 共用的 Manifest V3 扩展：在知乎网页版每条回答的操作栏加入朗读按钮，使用浏览器语音或腾讯云语音朗读当前回答，并高亮当前段落。

## 本地安装

1. 打开 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions`，打开「开发者模式」。
2. 点击「加载已解压的扩展」，选择本仓库里的 **`extension` 文件夹**。
3. 打开或刷新知乎问题／回答页面，如[示例回答](https://www.zhihu.com/question/8742907044/answer/2096610574620800318)。在回答的赞同、反对按钮旁点击「🔊 朗读」。
4. 朗读时，同一按钮可暂停、继续；点击「停止」结束。选择同一页面上的另一条回答会切换朗读。
5. 要调整语音服务、声音和语速，在扩展管理页面打开本扩展的「扩展选项」。设置在下次开始朗读时生效。

修改扩展文件后，在扩展管理页面重新加载扩展，再刷新知乎页面。卸载可在同一管理页面完成。

## 腾讯云配置

1. 自行开通[腾讯云语音合成服务](https://console.cloud.tencent.com/tts)，确认服务、音色和资源包可用。参阅[计费说明](https://cloud.tencent.com/document/product/1073/34112)：通用语音合成免费资源包需领取，按音色类别分别提供额度，自领取起三个月有效、每账号限领取一次；超额后是否继续计费取决于购买的资源包和后付费设置。不同音色价格不同，以控制台和最新计费规则为准。
2. 建议在[访问管理](https://cloud.tencent.com/document/product/1073/95485)中使用单独子账号，只授予 `tts:TextToVoice` 操作权限（该操作为操作级权限，资源为 `*`），然后在腾讯云创建该子账号的 API 密钥。请勿把密钥发给他人或写入代码。所选的 [TextToVoice 基础语音合成接口](https://cloud.tencent.com/document/api/1073/37995)使用 SecretId 和 SecretKey 的 TC3 签名，无需额外填写 AppId；本扩展不支持需要 Token 的临时密钥。
3. 在扩展选项中选择「腾讯云语音合成」，选择音色，**在自己的浏览器中**填写 SecretId 和 SecretKey 并保存。留空会保留现有密钥；更换时同时填写两项，也可用「删除已保存的密钥」清除。刷新知乎页面，点击一条允许访问的回答旁的朗读按钮，检查声音、段落高亮、暂停、继续和停止；再试 1.25× 和 1.5× 以及切换标签页。遇到错误时按页面提示检查服务开通、权限、额度、音色及网络。
4. 若之前已安装旧版，先在扩展管理页面重新加载扩展并接受新增的腾讯云域名访问权限，再刷新知乎页面。

腾讯云模式会将所选回答文本分段发送到腾讯云，并可能产生费用。扩展仅向 `https://tts.tencentcloudapi.com/` 请求合成；停止会取消正在等待的请求，但腾讯云可能已接收或计费。密钥保存在 `chrome.storage.local`，限制内容脚本直接访问，但本地存储并非加密保险箱：可访问浏览器配置或扩展数据的人仍可能读取。建议使用权限受限的子账号，必要时在腾讯云禁用或轮换密钥。

## 工作方式与限制

- 直接读取当前回答在页面中的正文节点，不操作剪贴板。扩展会尝试展开正文；页面结构变化、登录、付费或折叠等限制可能导致正文不完整。图片、视频、部分公式及非文本内容不会被完整朗读。
- 默认使用浏览器语音，可用声音由浏览器和系统决定，也可能是浏览器提供的网络声音。选用腾讯云后，扩展按段落拆成短文本逐段合成；一次只请求一段，段落之间可能有等待。每个合成片段开始播放时高亮所属段落，完成或停止后移除高亮。
- 腾讯云以正常语速合成并按所选倍速播放；浏览器语音通过 Web Speech API 的 rate 设置速度，实际效果取决于声音和浏览器。设置在下一次开始朗读时生效，不会实时改变正在播放的内容。
- 页面动态增加回答时会添加按钮。不同标签页各自控制朗读，浏览器后台休眠、网络或自动播放限制可能中断播放。停止不会让已发送的文字从腾讯云撤回。

## 开发与验证

需要 Node.js 和 npm：

```sh
npm ci
npm test
```

测试使用模拟页面、网络及语音引擎，覆盖正文提取、朗读控制、切换回答、动态加载、分段、TC3 签名、凭据隔离和腾讯云请求期间的暂停与停止。模拟测试不等于真实云端合成成功；音质、音频播放、后台行为、权限和腾讯云账号配置仍需在目标浏览器使用自己的凭据实测。

`extension/extract.js` 负责页面提取；`extension/speech.js` 提供浏览器和腾讯云播放实现；`extension/background.js` 在扩展后台读取凭据并请求腾讯云，`extension/tencent.js` 实现 TC3 签名；`extension/content.js` 负责页面与播放状态。
