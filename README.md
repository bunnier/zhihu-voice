# 知乎回答朗读

Chrome 和 Microsoft Edge 共用的 Manifest V3 扩展：在知乎网页版回答和推荐流文章的操作栏加入朗读按钮，使用浏览器语音或腾讯云语音朗读当前内容，并高亮当前段落。

## 本地安装

在项目目录运行 `npm run build:extension`，生成 `dist/zhihu-voice`。只需要 Node.js 和 npm，无需安装依赖或编译；脚本只复制扩展运行所需的文件。重复运行会更新这个目录，但如果里面有额外文件或生成后被修改，脚本会停止并保留原目录，请先自行备份或移走这些文件。

1. 打开 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions`。
2. 打开页面中的「开发者模式」。
3. 点击「加载已解压的扩展」，选择生成的 **`dist/zhihu-voice` 文件夹**，不是仓库根目录。如果之前加载过同一个项目，请先移除或禁用旧扩展，以免重复出现朗读按钮。
4. 打开或刷新知乎推荐页或问题／回答页面，如[示例回答](https://www.zhihu.com/question/8742907044/answer/2096610574620800318)。在内容的赞同、反对按钮旁点击「🔊 朗读」。
5. 朗读时，同一按钮可暂停、继续；点击「停止」结束。选择同一页面上的另一条内容会切换朗读。切换到其他浏览器标签页后，播放是否继续受浏览器后台策略影响；关闭、离开或刷新回答页面会停止。
6. 要调整声音和语速，在浏览器扩展管理页面中找到「知乎回答朗读」，打开「详细信息」中的「扩展选项」。选择语音服务、声音和速度后，可先点击「试听当前选择」播放固定中文示例，再保存设置；保存后下次开始朗读时生效。支持 1.25×、1.5× 等常用倍速。更改选项或关闭设置页会停止试听。

修改扩展文件后，再运行 `npm run build:extension`，在扩展管理页面点击重新加载，然后刷新知乎页面。卸载可在同一管理页面完成。也可以直接加载源码 `extension` 目录；这样修改后只需重新加载扩展，无需运行打包命令，但不要同时启用两个副本。

## 腾讯云配置与试听

1. 自行开通[腾讯云语音合成服务](https://console.cloud.tencent.com/tts)，确认服务、音色和资源包可用。参阅[计费说明](https://cloud.tencent.com/document/product/1073/34112)：通用语音合成免费资源包需领取，按音色类别分别提供额度，自领取起三个月有效、每账号限领取一次；超额后是否继续计费取决于购买的资源包和后付费设置。不同音色价格不同，以控制台和最新计费规则为准。
2. 建议在[访问管理](https://cloud.tencent.com/document/product/1073/95485)中使用单独子账号，只授予 `tts:TextToVoice` 操作权限（该操作为操作级权限，资源为 `*`），然后在腾讯云创建该子账号的 API 密钥。请勿把密钥发给他人或写入代码。所选的 [TextToVoice 基础语音合成接口](https://cloud.tencent.com/document/api/1073/37995)使用 SecretId 和 SecretKey 的 TC3 签名，无需额外填写 AppId；本扩展不支持需要 Token 的临时密钥。
3. 在扩展选项中选择「腾讯云语音合成」，选择音色，**在自己的浏览器中**填写 SecretId 和 SecretKey，点击「保存密钥」。更换时同时填写两项，也可用旁边的「删除已保存的密钥」清除。密钥操作与「保存页面设置」相互独立。刷新知乎页面，点击一条允许访问的回答旁的朗读按钮，检查声音、段落高亮、暂停、继续和停止；再试 1.25× 和 1.5× 以及切换标签页。遇到错误时按页面提示检查服务开通、权限、额度、音色及网络。
4. 若之前已安装旧版，先在扩展管理页面重新加载扩展并接受新增的腾讯云域名访问权限，再刷新知乎页面。

设置页的腾讯云试听使用已保存的密钥，将页面显示的固定示例发送至腾讯云，可能产生费用；新输入的密钥点击「保存密钥」后即可用于试听，音色和倍速则无需预先保存；如需用于之后的朗读，还需点击「保存页面设置」。

腾讯云模式会将所选内容文本分段发送到腾讯云，并可能产生费用。为减少停顿，播放时最多提前请求下一段，因此暂停或停止前下一段可能已发送并计费；暂停期间不会开始新的预取。扩展仅向 `https://tts.tencentcloudapi.com/` 请求合成；停止会取消正在等待的请求，但腾讯云可能已接收或计费。密钥保存在 `chrome.storage.local`，限制内容脚本直接访问，但本地存储并非加密保险箱：可访问浏览器配置或扩展数据的人仍可能读取。建议使用权限受限的子账号，必要时在腾讯云禁用或轮换密钥。

## 工作方式与限制

- 直接读取当前回答或推荐流文章在页面中的正文节点，不操作剪贴板。扩展会尝试展开正文；页面结构变化、登录、付费或折叠等限制可能导致正文不完整。展开失败时会提示并只朗读可见正文，不绕过访问限制。图片、视频、部分公式及非文本内容不会被完整朗读。专栏独立文章页面、想法、视频及其他卡片类型暂不支持。
- 默认使用浏览器语音，可用声音由浏览器和系统决定，也可能是浏览器提供的网络声音。选用腾讯云后，扩展按段落拆成短文本逐段合成；一次只请求一段，段落之间可能有等待。每个合成片段开始播放时高亮所属段落，完成或停止后移除高亮。
- 腾讯云以正常语速合成并按所选倍速播放；浏览器语音通过 Web Speech API 的 rate 设置速度，实际效果取决于声音和浏览器。设置在下一次开始朗读时生效，不会实时改变正在播放的内容。
- 页面动态增加回答或文章时会添加按钮。不同标签页各自控制朗读，浏览器后台休眠、网络或自动播放限制可能中断播放。停止不会让已发送的文字从腾讯云撤回。

## 开发与验证

需要 Node.js 和 npm：

```sh
npm ci
npm test
```

浏览器语音会合并短段落以减少反复启动；段落高亮依赖语音引擎的边界事件，不提供边界事件的声音可能只在合并片段开始时更新高亮。网络或合成较慢时，腾讯云段落间仍可能等待。

测试使用模拟页面、网络及语音引擎，覆盖正文提取、朗读控制、切换回答、动态加载、分段、TC3 签名、凭据隔离、设置页试听和腾讯云请求期间的暂停与停止。模拟测试不等于真实云端合成成功；音质、音频播放、后台行为、权限和腾讯云账号配置仍需在目标浏览器使用自己的凭据实测。

`extension/extract.js` 负责页面提取；`extension/speech.js` 提供浏览器和腾讯云播放实现；`extension/background.js` 在扩展后台读取凭据并请求腾讯云，`extension/tencent.js` 实现 TC3 签名；`extension/content.js` 负责页面与播放状态。
