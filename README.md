# 知乎回答朗读

Chrome 和 Microsoft Edge 共用的 Manifest V3 扩展：在知乎网页版每条回答的操作栏加入朗读按钮，使用浏览器语音朗读当前回答，并高亮当前段落。

## 本地安装

1. 打开 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions`，打开「开发者模式」。
2. 点击「加载已解压的扩展」，选择本仓库里的 **`extension` 文件夹**。
3. 打开或刷新知乎问题／回答页面，如[示例回答](https://www.zhihu.com/question/8742907044/answer/2096610574620800318)。在回答的赞同、反对按钮旁点击「🔊 朗读」。
4. 朗读时，同一按钮可暂停、继续；点击「停止」结束。选择同一页面上的另一条回答会切换朗读。
5. 要调整声音和语速，在扩展管理页面打开本扩展的「扩展选项」。设置在下次开始朗读时生效。

修改扩展文件后，在扩展管理页面重新加载扩展，再刷新知乎页面。卸载可在同一管理页面完成。

## 工作方式与限制

- 直接读取当前回答在页面中的正文节点，不操作剪贴板。扩展会尝试展开正文；页面结构变化、登录、付费或折叠等限制可能导致正文不完整。图片、视频、部分公式及非文本内容不会被完整朗读。
- 使用 Web Speech API 朗读并按段落高亮，可用声音及其音质由浏览器和系统决定，也可能是浏览器提供的网络声音。语速的实际效果取决于声音和浏览器。
- 页面动态增加回答时会添加按钮。不同标签页各自控制朗读，后台策略可能中断播放；关闭、离开或刷新回答页面会停止。
- 模拟测试覆盖了自动展开，但真实知乎页面中自动展开后语音未开始的情况仍需进一步验证和排查。不能据此保证真实页面能够开始朗读。

## 开发与验证

需要 Node.js 和 npm：

```sh
npm ci
npm test
```

测试使用模拟页面和语音引擎，覆盖正文提取、朗读控制、切换回答、动态加载、分段和页面更新。模拟测试不能替代真实知乎页面及目标浏览器中的验证。

`extension/extract.js` 负责页面提取；`extension/speech.js` 提供浏览器语音播放；`extension/background.js` 提供设置读取；`extension/content.js` 负责页面与播放状态。
